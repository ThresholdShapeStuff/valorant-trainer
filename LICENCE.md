## 🧩 About

**Valorant Trainer** is a comprehensive mod menu for Valorant featuring aim assist, ESP, radar, recoil control, triggerbot, and customizable configs.

Based on popular tools like **Valorant Hacks**, **Aimmy**, and **Sunset**.

## ✨ Features

### 🎯 Aim Assist
- Aimbot — automatically aim at enemies with customizable smoothness
- Triggerbot — automatically shoot when crosshair is on enemy
- Recoil Control — reduce weapon recoil for better accuracy
- Aim Smoothing — adjust aim speed for natural movement

### 👁️ Visuals
- ESP — see enemies through walls with boxes, names, health, and distance
- Radar — mini-map showing enemy positions
- Skeleton ESP — view enemy skeletal structure
- Item ESP — highlight weapons and abilities

### ⚙️ Configuration
- Customizable hotkeys — set your own toggle keys
- Save & Load Configs — multiple profiles for different playstyles
- Streamproof — hide overlay from streaming software
